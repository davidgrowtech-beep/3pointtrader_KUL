The 3-Point Method3 பாயிண்ட் முறை என்றால் என்ன?

E
Point 1 — Entry
சரியான நேரத்தில் market-ஐ எப்படி entry பண்றது என்று கற்றுக்கொள்வீர்கள்.

Point 2 — Target
Profit book பண்ண சரியான Target level-ஐ எப்படி வைப்பது என்பதை பார்ப்போம்.
SL
Point 3 — Stop-Loss
Capital-ஐ பாதுகாக்க Stop-Loss எப்படி set பண்றது என்பதை practical-ஆ கற்போம்.
